Privacy policy

Wasted Daily Uploader · Last updated 19 November 2026

Who this applies to

Wasted Daily Uploader is a private tool run by the owner of the Wasted Daily channel. It is used only to manage the owner's own YouTube channel and Instagram account. It is not offered to the public, and no other person signs in to it.

What data the tool accesses

When the owner signs in with Google, the tool requests permission to upload videos to the owner's YouTube channel (youtube.upload) and to read that channel's own video details and statistics (youtube.readonly). With Instagram, it requests permission to publish Reels to the owner's account and to read that account's basic information and post statistics.

How the data is used

The tool uses this access only to upload and schedule the channel's own videos, set their titles, descriptions and tags, and record view counts so the owner can see which videos perform well. It does not access, collect or process data about any other user.

Storage

Access tokens and video statistics are stored only on the owner's own computer. They are not sold, shared, transferred to third parties or used for advertising. Nothing is stored on a server operated by the tool.

Google API Services

Wasted Daily Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google account's security settings (myaccount.google.com/permissions) or from Instagram's Apps and websites settings. Revoking access stops the tool from uploading or reading data, and the owner can delete the locally stored tokens.
